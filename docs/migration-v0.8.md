# 升级到 v0.8.0

v0.8.0 保留剧本分析、单资产概念设计和图片提示词流程，并加入场景导演、中文分镜正文、导演知识管理和显式 Seedance 镜头提示词流程。插件共包含 38 个技能。

## 安装与更新

首次安装见 [README](../README.md#安装与更新)。已有安装可运行：

```bash
codex plugin marketplace upgrade skill-orchestrator-private
codex plugin add skill-orchestrator@skill-orchestrator-private
codex plugin list
```

确认实际安装版本为 `0.8.0` 后，新建一个 Codex 任务加载技能。不要手工修改 Codex 配置或插件缓存。

## 从已有成果继续

| 你已有的材料 | 下一步 |
| --- | --- |
| 原始剧本 | 在计划模式调用 `$ai-script-breakdown`，确认计划后切回默认模式执行 |
| 旧的剧本拆解 | 先校验完整性和来源记录；缺少来源指纹或源文件已经变化时重新分析 |
| 已验证的剧本拆解 | 选择同一剧本中的 1–2 场，调用 `$screenplay-scene-daoyanzu` |
| 已封存的场景导演包 | 调用 `$screenplay-shot-prose-compiler`，先确认正文校样，再生成全场 DOCX |
| 已封存的单资产需求及配套文件 | 校验通过后进入 `$image-prompt-team`；高影响设计变更返回概念导演 |
| 希望获得 Seedance 提示词 | 明确调用 `$seedance-shot-prompt-compiler`，并提供中文 Excel 镜头表模板 |

## 默认交付的变化

场景导演组先封存不含生成提示词的导演包，再调用正文编译器交付“一镜一段”的无表格中文 Word。真实机位切换可使用连续子镜号。旧式导演 Excel 仅在显式要求时走兼容路径。

正文编译器按已确认的导演决定写作；需要修改剧情、对白、接触、核心走位或道具状态时，返回导演组派生新版本。Seedance 编译器同样以封存导演包为事实边界，支持中文文生视频提示词，默认先校样。

资产概念导演面向用户默认交付一份《资产概念设计书》，机器交接文件保留在内部目录。可读设计书不能替代封存需求及配套机器文件。旧版缺少有效来源或确认记录的材料需要重新验证，不能通过改写版本号直接升级。

## 本地知识与隐私

公开包提供知识管理工具、空目录模板和通用规则，不携带私人课程原文、转换全文、用户审定记录或项目案例。自行导入资料时，应保存在仓库外的项目目录；只有经过用户审定的版本才能进入对应岗位。

此次发布保留公开 v0.4.0 历史，将经过整理的 v0.8.0 内容作为新的公开提交；中间开发版本不补发为正式 Release。
