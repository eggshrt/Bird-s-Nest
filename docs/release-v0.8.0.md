# Skill Orchestrator v0.8.0 · 从剧本到中文导演分镜

v0.8.0 将剧本分析、场景导演和中文分镜正文接成完整流程：上传剧本建立事实依据，选择同一剧本中的 1–2 场，经专业岗位设计与用户确认后，输出一镜或一个子镜一段的中文 Word。

## 本次发布

- **中文分镜 Word**：新增分镜正文编译器，将封存镜头编译为无表格 DOCX，整合摄影、动作、微表情、台词、声音与结束状态，支持连续子镜号。
- **场景导演组**：4 个常驻岗位与 7 个条件岗位协作，形成表演调度、摄影分镜、连续性和执行风险方案；关键决定经用户确认后封存。
- **独立提示词分支**：保留单资产图片提示词团队；明确调用 Seedance 编译器时，按用户模板生成中文文生视频提示词 Excel。
- **概念设计交付更集中**：面向用户交付一份中文资产概念设计书；机器交接文件继续保留并校验，减少重复上下文。
- **交接更严格**：来源、需求、设计决定与确认记录相互绑定，拒绝过期或被改动的上游材料；失败后支持恢复。
- **38 个技能说明**：重写中文 README，提供选择入口、输入输出、从零上手和完整技能目录。
- **公开包清理**：排除私人知识原文、转换全文和审定记录；删除示例项目痕迹，修复 Seedance 导出固定旧项目决定的问题。

## 使用方式

默认主流程：`ai-script-breakdown → screenplay-scene-daoyanzu → screenplay-shot-prose-compiler → DOCX`。

资产分支：`screenplay-concept-director → image-prompt-team → 中文图片主提示词`。

视频提示词分支：`封存导演包 → seedance-shot-prompt-compiler → XLSX`。

安装、示例和完整输入输出见 [README](../README.md)；已有项目见 [升级说明](migration-v0.8.md)。

## 验证范围

本次发布的自动验证以合成剧本、确定性假 Agent 和临时文档为材料，覆盖剧本拆解、需求交接、调度恢复、导演包、DOCX 和 XLSX 编译。实际测试结果见 [质量状态](quality-status.md)。

插件交付分析、设计、文档和文字提示词。真实图像或视频生成、模型输出质量，以及长时间真实多 Agent 运行不包含在本次自动验证结论中。
