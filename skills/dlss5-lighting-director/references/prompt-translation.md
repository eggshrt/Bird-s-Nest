# 把光学决定写成可见结果

只保留改变当前可见结果或保护不变量的句子。按本次素材顺序或原镜头时间线组织，既不堆术语，也不为精简删掉关键因果。

可用的表达骨架是：**来源/对象→表面或介质→可见响应→随角度、遮挡或既有运动发生的变化→保持项**。这是组织关系，不是固定逐项表格。

例如已确定金属转子旋转时，可以写“机械肋条进入受光角后出现短而集中的银灰亮斑，转入背光后收暗；固定外壳保持原位，槽影随实体转动变化”。先有旋转事实，才有此响应；不能从需要动态光反推必须让部件旋转。

“Roughness 0.4”“IOR 1.5”等若仅用于内部推演，转成反光宽度、倒影清晰度、透射与曲缘偏折等可见描述。用户明确要渲染建议时可另列数值及适用约定，不把它们塞进视频API参数或宣称已经应用。Structure/Tone Intensity、保护范围借鉴的是控制职责，不是普适0–100滑块。

单独光影段默认是一套可复制正文，说明身份与范围所必需的对象名称可以保留。不输出另一份分析长稿、逐部门意见、方法采用证明或未经请求的技术表。用户只问诊断时先给诊断，不强制写最终词。

完整合稿只在用户要求时进行：替换或合并光影/材质相关段落，去掉同一对象的旧矛盾描述，未授权部分沿用；同步出现同一光学关系的镜头段落，避免总纲说透明而逐镜仍写不透。若解决矛盾必须改变上游已批准事实，先明确冲突，不偷偷选择。沿用当前任务最新决定，不恢复较早被删除的元素。

在已有image-prompt-team中，只编译已确认的VisualPromptSpec，保留原来的段落顺序、单资产与确认门，不附加本Skill的自定义标题/格式或第二资产。在Seedance或分镜正文编译链，只表达封存决定，不借光学深化重做摄影、机械动作、对白或场景事件。新的实质设计缺口回上游灯光岗位。

关键因果不是冗词：主光固定于世界空间而镜面高光随视角变化、光只影响附近无遮挡表面、玻璃反射与内景可见范围的区别，不能在salience压缩时删成“光影真实高级”。可以去掉重复形容词、相机名或无效数值。
