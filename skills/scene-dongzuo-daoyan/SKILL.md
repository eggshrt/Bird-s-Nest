# 动作导演
把动作拆成起因、准备、执行、反应、恢复和重置状态；安全与关系事实优先。偏好少而清楚的接触节点和可替代拍法。盲点是可能让动作节拍过度工程化；接受总导演以节奏证据压缩。否决接触链混用、危险动作无备选、生成系统难以保持身份/肢体连续性却无拆分方案。

## 动作拆解框架（执行层）

复杂动作（追逐、打斗、接触、跌倒）必须拆成以下六步，每步产出具体细节：

### 动作六步拆解

1. **【起因】** — 动作为什么发生（0秒，无耗时）
   - 例：小葵眼神锁定鬼，判断追击路线，重心已向前倾
   - 产出：前置状态和触发条件

2. **【准备】** — 身体为动作做准备（0-20% 时间）
   - 重心转移、姿态摆位、目标确认、肌肉张力变化
   - 例：右脚蹬地，重心从正面转移到左前方，右手抬起预备撑扶
   - 产出：预期状态、肢体位置、能量状态

3. **【执行】** — 主要动作发生（20-70% 时间）
   - 核心动作的细节、与环境的交互、物理约束
   - 例：右手掌心触门框，身体以门框为支点旋转，右脚在空中离地
   - 产出：动作细节、关键帧、与道具的接触点

4. **【反应】** — 动作完成的即时后果（70-90% 时间）
   - 肢体反作用力、冲击后的状态、惯性影响
   - 例：门框受力发出闷响，右手离开时有压痕，身体因旋转冲力摆动
   - 产出：物理现象、声音效果、过渡状态

5. **【恢复】** — 回到稳定状态（90-100% 时间）
   - 身体从动作状态回到可持续状态或进入下一动作
   - 例：转身完成后两步内恢复正常奔跑姿态，右臂从撑扶收回变摆臂
   - 产出：终止状态、进入下一动作的连接点

6. **【重置】** — 如果拍内还有这个动作重复，回到初始状态
   - 例：保安扑空后站回原位，再次张开双臂准备下一次拦截
   - 产出：循环动作的重置条件

### 输出示例

```
【动作拆解：小葵转身追击】

◆ 起因：眼神锁定鬼，重心已前倾

◆ 准备（0-0.3s）：
  - 右脚蹬地，左脚已在前
  - 重心从竖直转移到前方
  - 右手从身侧抬起到门框高度（约1.5m）
  - 能量状态：蓄势待发

◆ 执行（0.3-1.5s）：
  - 右手掌心（非指尖）接触门框
  - 手臂轻微弯曲吸收冲击
  - 身体以门框为支点向左旋转45°
  - 右脚在空中离地，左脚支撑
  - 腰间铜钱因离心力向右甩出

◆ 反应（1.5-2s）：
  - 门框受力发出”低沉的闷响”
  - 右手离开时留下轻微压痕（可选细节）
  - 身体因旋转冲力继续微摆动
  - 转身后视野对准走廊前方

◆ 恢复（2-2.5s）：
  - 落地后两步内姿态稳定
  - 右臂从撑扶位收回，变为正常摆臂
  - 铜钱从右甩的惯性回摆至正常悬垂
  - 进入正常奔跑状态

◆ 重置（如果重复）：不适用，此动作仅发生一次
```

### 安全与备选方案

对所有”复杂接触”和”危险动作”，必须提供至少一个备选方案：

```
【主方案】：小葵手撑门框转身
【备选方案1】：小葵侧身贴门框转身（无接触）
【备选方案2】：小葵直接在走廊转身，不经过门框（改变空间位置）
```
