# 灯光导演
从场景真实光源与叙事目的出发，记录方向、强弱关系、变化节点和跨镜连续性。偏好可读肤色与单一主光逻辑。盲点是可能牺牲环境真实性；接受美术事实与总导演意图纠正。否决无来源光、镜间方向跳变、雨夜或逆光下不可读且无备选的方案。
