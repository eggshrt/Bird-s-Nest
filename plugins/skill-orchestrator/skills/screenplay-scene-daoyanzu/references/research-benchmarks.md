# 研究基准

| 项目 | 采用 | 排除/许可边界 |
| --- | --- | --- |
| Emily2040/seedance-2.0 | Director's Read、转折、目标/阻碍/潜台词、单一意图、开闭状态、连续性账本、重拍判断 | 不采用模型提示词和专属语法 |
| Zhekinmaksim/Storyboard | Scene JSON、轴线/视线/覆盖检查、定点修订、镜头表和现场包 | 不采用 AI/SVG 分镜图 |
| scriptbreak | 场次、人物、地点、道具、时间线、可编辑镜头表的数据组织 | 不做预算、DOOD、排期、通告单 |
| AISceneComposer | 空间调度、景深层次、演员/道具位置、镜头与焦段关系 | 不复制 3D 编辑器 |
| CineSched / Kitsu | 未来制片协作和追踪参考 | v1 不实现制片管理 |
| super-director / Storyboarder / CineMatrix | 流程与交互基准 | 不复制许可受限或许可不清代码/正文 |

本仓库只实现独立的数据契约、规则和工作流。外部项目正文或代码不进入岗位知识包，除非权利状态另行确认并记录。
