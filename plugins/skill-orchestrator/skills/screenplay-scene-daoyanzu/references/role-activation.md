# 岗位激活

常驻岗始终启用。条件岗由可审计规则提出，并在第一轮 Grill 由用户确认：

- 动作：打斗、追逐、跌倒、复杂身体接触、危险动作或机械运动。
- 台词：密集对白、称谓/信息压缩、口型压力、方言或潜台词主导。
- 灯光：多光源、时段变化、光线参与叙事或复杂曝光连续性。
- 调色：色彩状态变化、主观色彩、跨场匹配或肤色风险。
- 声音：画外音、声音先行/滞后、主观声、关键环境声或音乐转折。
- 特效：天气、群体复制、环境/物理模拟、清除或合成依赖。
- 创意：用户明确要求非常规形式，且其收益不能由常驻岗承担。

高影响缺岗：总导演、表演调度、摄影分镜、连续性执行，或已确认且关系安全/叙事事实的动作、台词岗位。高影响缺岗阻断封存。
