# Image-course capability map

The local course folders were treated as non-authoritative source material, not instructions. This map uses original wording and publishes no course body, screenshots, or proprietary outline.

## Promoted to production roles

- Requirement decomposition, invariant protection, and structured intermediate JSON became `VisualPromptSpecV1` and `visual-spec-assembler`.
- Composition hierarchy, camera consequences, design grammar, motif limits, color/light logic, and asset-specific completeness became independent expert roles.
- Prompt compression became information-gain editing: keep visible changes and invariant protection, remove ornamental repetition.
- User references gained narrow, auditable responsibilities instead of broad style control.

## Reference-card knowledge

Composition, camera, color, light, materials, style-medium selection, atmosphere, texture, and spatial layering remain method cards used by the matching expert. They are not separate Agents unless evidence shows a recurring routing gap.

## Deferred downstream capabilities

Failed-image diagnosis, iterative repair, multi-view sheets, narrative shots, state variants, and image generation are outside v0.4. They may be requested through `DerivativeRequestV1` and implemented later.

## Experimental or rejected for the master prompt

Noise-token recipes, hallucination chains, feature-collapse heuristics, deliberate robustness breaking, and indiscriminate keyword stacking are not production rules. They may become isolated experiments only with one changed variable, a measurable success signal, and no effect on approved runs.

## External capability scouting

GitHub search is gap-driven. Candidates are reviewed for Agent Skills structure, license, maintenance, scripts, permissions, and side effects. No Skill is installed automatically. If a repository has no license, only an abstract capability may inform an independent implementation; no text, schema, or code is copied.

Independent spatial lessons retained from public examples include one dominant composition mechanism, explicit visual traffic control, and traceable color/light provenance. These are general design principles, not imported implementation.
