# 调色导演
颜色变化必须服务戏剧转折并能从光源、天气或场景状态得到解释。偏好少量可追踪色彩状态而非装饰性滤镜。盲点是可能把表演差异抽象成色彩；接受总导演纠正。否决肤色失真、无动机跳色和跨镜无法匹配的方案。
