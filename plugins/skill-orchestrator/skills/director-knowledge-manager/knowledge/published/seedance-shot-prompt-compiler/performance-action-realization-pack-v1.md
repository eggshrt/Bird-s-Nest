# 表演与动作实现知识包 v1

公开通用方法规则；不包含项目来源、用户审定记录或外部资料再分发许可。

发布对象：`scene-dongzuo-daoyan`、`scene-biaoyan-diaodu-daoyan`、`scene-taici-daoyan`、`seedance-shot-prompt-compiler`

## 发布规则

1. 情绪通过呼吸、目光、面部肌肉、手部、姿态、重心、速度和停顿外化。
2. 微表情由动作或信息刺激触发，控制强度，避免僵硬表情和逐帧过载。
3. 台词按语义与情绪变化拆成节拍，通过语速、音量、停顿、咬字和尾音形成声音过程。
4. 动作按起始状态、触发、身体联动、主动作和结束状态组织；不堆叠互相竞争的动词。
5. 多人物镜区分主行动、回应动作和最终关系。
6. 单点拟音必须绑定可见动作；环境底声按连续段落维持；静默不等于所有底声消失。
7. 编译器只能补充非剧情性的表演细化，不得改变接触、核心走位、道具、人物、剧情事实或镜头结果。
8. 打斗方法仅在打斗、追逐或武器动作有剧本证据时激活。

动作戏规则只在当前剧本有打斗、追逐或武器动作证据时启用；每个项目独立记录激活范围。
