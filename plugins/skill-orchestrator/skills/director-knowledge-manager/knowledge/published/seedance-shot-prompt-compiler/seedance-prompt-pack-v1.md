# Seedance 镜头提示词专用知识包 v1

公开通用方法规则；不包含项目来源、用户审定记录或外部资料再分发许可。

发布对象：`seedance-shot-prompt-compiler`

隔离状态：仅提示词编译器可用，不进入导演岗位。

历史兼容版本；新编译使用 [v3](seedance-prompt-pack-v3.md)。

## 精炼规则

1. 一镜只承载一个主要可见动作、一个主要运镜和一个明确结束状态。
2. 把情绪转成姿态、目光、呼吸、手部、重心、速度和停顿等可观察表演。
3. 摄影机位置、角度、焦段和运动必须互相兼容；方向以画框或摄影机为参照。
4. T2V 镜头必须自足地说明主体、空间、动作、表演、摄影、光色和镜头专属约束。
5. 普通镜头使用自然顺序；多步因果使用阶段顺序，不使用秒级时间码。
6. 完整台词、音效和环境声留在独立列；提示词只保留同步时机。
7. 不堆砌通用画质词，不使用图生视频引用语法，不用冗长负面提示词。
8. 生成结果失败时只修改造成失败的具体层，不重新发明导演设计。

## 表达原则

多步因果使用阶段顺序，不预设硬秒数。首句建立主体、动作和摄影关系，不规定机械语序。
