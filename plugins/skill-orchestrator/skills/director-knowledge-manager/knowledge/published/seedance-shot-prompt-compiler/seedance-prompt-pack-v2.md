# Seedance 镜头提示词专用知识包 v2

公开通用方法规则；不包含项目来源、用户审定记录或外部资料再分发许可。

发布对象：`seedance-shot-prompt-compiler`

隔离状态：仅提示词编译器可用，不进入导演岗位。

继承版本：[v1](seedance-prompt-pack-v1.md)。新编译使用 [v3](seedance-prompt-pack-v3.md)。

## 精炼规则

1. 一镜只承载一个主要可见动作、一个主要运镜和一个明确结束状态。
2. 把情绪转成姿态、目光、呼吸、手部、重心、速度和停顿等可观察表演。
3. 摄影机位置、角度、焦段和运动必须互相兼容；方向以画框或摄影机为参照。
4. T2V 镜头必须自足地说明主体、空间、动作、表演、摄影、光色和镜头专属约束。
5. 普通镜头使用自然顺序；多步因果使用阶段顺序，不使用秒级时间码。
6. 台词、音效和环境声既保留在独立结构化列，也在提示词的实际发生位置完整嵌入，使单镜提示词可独立使用。
7. 不给每镜添加通用画质或比例前缀，不在文末添加“与某列同步”“不新增对白”等审计声明。
8. 用户尚未提供参考素材时，不发明图片引用；未来素材负责锁定人物、光线或空间时，不以泛化连续性句占位。
9. 不堆砌通用画质词，不使用图生视频引用语法，不用冗长负面提示词。
10. 生成结果失败时只修改造成失败的具体层，不重新发明导演设计。

## 版本变化

v2 将完整台词和声音嵌入实际发生位置，使单镜提示词可独立使用。多步因果采用阶段顺序，不预设硬秒数。首句建立主体、动作和摄影关系，不规定机械语序。
