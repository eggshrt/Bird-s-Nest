# Seedance 镜头提示词专用知识包 v3

公开通用方法规则；不包含项目来源、用户审定记录或外部资料再分发许可。

发布对象：`seedance-shot-prompt-compiler`

隔离状态：仅提示词编译器可用，不进入导演岗位。

继承版本：[v2](seedance-prompt-pack-v2.md)。

## 增量规则

1. 每镜声音分为全场环境声、单点音效、静默／留白；单点拟音跟随动作写入提示词。
2. 台词、动作、微表情、对手反应和声音按真实节拍交错，不把完整台词与表演分成两个孤立段落。
3. 同一主镜号可以多次切镜且不设数字上限，但每次切换必须对应新的信息、表演或反应节拍，并完整说明摄影参数。
4. 比例和模型配置仍保存于工作表级，不在每镜重复。
5. 图片素材未提供前不写引用语法。
6. 编译器只拥有有限表演细化权，不得重新导演剧情或改变封存镜头的事实边界。
