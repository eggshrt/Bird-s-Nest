# 表演与动作实现规则

知识包版本：`performance-action-realization-pack-v1`


## 有限表演细化

- 把抽象情绪落实为呼吸、目光、面部肌肉、手指、肩背、姿态、重心、速度和停顿。
- 微表情必须有身体动作或信息刺激作为原因，避免表情独立变化和持续满强度表演。
- 台词按语义和情绪变化拆成节拍；每个节拍写清语速、音量、停顿、咬字或尾音变化，并与动作或反应交错。
- 动作链遵循“起始状态—触发—预备／身体联动—主动作—结束状态”。简单动作不强行扩写完整链。
- 多人物镜分别写主行动、回应动作与两人最后停留的关系，避免所有人同时抢动作。
- 单点拟音必须由可见动作触发；没有触碰就不能出现触碰声。

## 权限边界

可以补充：眨眼、吞咽、鼻息、换气、指尖收紧／松开、衣料轻响、肩背细微变化、原地重心调整及已有动作产生的拟音。

不得补充：新的人物接触、新步数或新路径、新道具操作、新人物、新剧情事件、原镜头之外的结果、改变权力调度的明显动作。

## 动作戏激活

打斗、追逐和武器动作的方法只在当前剧本证据明确支持时启用。缺少证据时保持未激活；每个项目独立记录依据和范围。
