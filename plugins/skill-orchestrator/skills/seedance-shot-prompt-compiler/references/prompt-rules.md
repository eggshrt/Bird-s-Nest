# Seedance 2.0 T2V 编译规则

知识包版本：`seedance-prompt-pack-v3`


## 单镜结构

每条提示词是可单独复制的中文拍摄简报：主体与主要动作；场景和空间关系；可见表演；景别、角度、机位、焦段和一个主要运镜；物理光色与必要声音时机；结束画面；少量镜头专属约束。

- 普通镜头按自然动作顺序写。只有同镜存在多步因果时使用“先、随后、最后”，不写秒级时间码。
- 情绪必须变成可观察动作，例如目光停顿、呼吸变化、下颌或手指状态、重心和动作速度；不得只堆抽象情绪词。
- 一个镜头只保留一个主要运镜。固定机位也是明确选择。
- 使用以摄影机为参照的画面左/右、靠近/远离、前景/中景/后景，不使用含糊的“向前”。
- “台词／旁白”和“音效／环境声”列继续保存结构化原文；视频提示词也必须在人物说话、动作或环境建立的实际位置完整嵌入本镜台词与相关声音，不能只写“与某列同步”。
- 台词要放进说话者的表演过程，声音要放进对应动作或环境过程；不得把台词和音效机械堆到文末。
- 不在每镜重复“16:9古装写实电影画面”等工作表级配置，也不写“口型与某列同步”“不新增对白”等审计式尾注。
- 未提供实际参考素材及其角色映射前，不写 `@图片` 等引用语法。用户计划以后用参考素材锁定人物、光线或空间时，不用泛化的“保持连续”句占位；只保留当前镜头真正需要的轴线、位置、视线和动作约束。
- 不复制通用画质词，不使用 `@图片`、`@Image`、I2V、参考首帧或负面提示词清单。
- 不写逐镜秒数。比例、模式和模型作为工作表级配置保存。
- 声音分为“全场环境声、单点音效、静默／留白”。全场环境声只在剧本或连续性证据支持的镜头段落中持续；单点音效紧跟动作写入括号；静默必须说明哪些声音仍然存在。
- 长对白按真实情绪或信息节拍穿插台词、动作、微表情、对手反应和声音。允许在同一主镜号内多次切镜，但每次必须写清景别、角度、机位、焦段、运镜与主体，并与一个节拍绑定。
- 允许的新增内容仅限非剧情性表演细化；禁止新增接触、核心走位、道具、人物、剧情事实或结局状态。

## 分歧裁决

采用自适应顺序：一镜一重点时写自然顺序；多步因果只写阶段顺序，不制造精确秒数。镜头与主体谁先写不设机械语序，但首句必须同时明确主要主体、可见动作和拍摄关系。
