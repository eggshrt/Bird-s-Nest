# 一镜一段分镜正文标准

标准版本：`shot-prose-standard-v1`

## 适用范围

本标准定义一镜一段的通用组织方式。参考文档只可提供表达和版式依据，其剧情、对白、接触、天气、人物和临时标记不得转移为当前项目事实。彩色字、修订标记、错别字、临时备注和未裁决备选不属于正文标准。

## 场次层

每个场次标题只显示一次集号、场号和场名，例如 `E001 S001 场景名称`。标题后用一个自然段交代：

1. 本场导演意图。
2. 空间关系与主轴线。
3. 天气与光线状态。
4. 持续环境声。
5. 人物起始位置和动作状态。

这些信息是场次基线。镜头正文只写变化，避免每段机械重复天气、底声和连续性口令。

## 镜头层

普通镜头显示 `C001`。同一叙事节拍内存在多个独立机位时，各自显示 `C001-1`、`C001-2`，每个子镜独立成段并具备完整拍摄含义。

每段采用连续导演语言，不做字段清单：

1. 先确定景别与摄影机和主体的关系；角度、焦段、轴线只在有实际影响时写。
2. 再建立前景、中景、后景以及人物在画面左／右、远／近的位置。
3. 按时间顺序把动作、走位、目光、呼吸、微表情、台词、对手反应和单点音效穿插起来。
4. 最后明确停止动作、人物关系或结束构图。

同一镜内的连续移动、摇移、推拉和环绕可留在一段；真正切换机位、反打或插入镜必须成为独立子镜或下一主镜。

## 表演与声音

- “痛苦、隐忍、不舍”等情绪标签必须伴随可观察的表演外化。
- 外化维度包括呼吸、目光、眼睑、眉部、嘴角、下颌、手指、肩背、姿态、重心、动作速度与停顿。
- 台词放在说话动作实际发生的位置，不能全部堆在段末。
- 场次基线声明持续环境声；镜头段落只写新增、增强、减弱、静默或与动作同步的声音。
- 没有可见动作或接触时，不得新增相应拟音。

## 定稿边界

最终正文不得保留未选择的景别、机位或构图方案，也不得出现“待定”“可以是”“也可以”“什么的”等制作占位语。技术问题由总导演在封存前裁定；对白、剧情、接触、人物关系、道具状态和核心走位的改变必须重新 Grill。


本标准不生成 Seedance 或其他平台提示词。模型适配属于下游显式流程。
