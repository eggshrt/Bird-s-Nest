# Skill Orchestrator - AI 影视制作助手

让 AI 代理（Claude、GPT）帮你做影视短剧制作：从剧本到分镜、从角色定妆到视频提示词、从导演会诊到平台交付。中文原生，口语化需求也能精准理解。

## 能做什么

- **剧本拆解**：上传剧本文档，自动生成分镜、场记表、资产清单
- **角色与场景设计**：描述需求（"李博士，30 多岁科学家，沉稳内敛"），生成定妆方案和图片提示词
- **导演会诊**：一个镜头多个岗位（摄影、灯光、连续性、声音）并行评审，汇总建议
- **视频提示词**：把分镜转成即梦、可灵、Seedance 等平台的提示词，可直接粘贴
- **逐镜优化**：改光影、调构图、修台词、查衔接，轻量快速
- **平台交付**：导出符合平台规范的格式，管理版本

## 三种用法，按需选择

- **轻量档**：改个小地方、问个单一问题，秒回，不走完整流程
- **标准档**：多人会诊、跨镜检查，几分钟出结果
- **正式档**：封存的导演包、提示词包，全程留审计，可追溯

## 中文用户友好

**口语化也能懂**："把第二镜的光弄高级点，顺便看看跟第三镜接不接得上，出个能直接贴即梦的提示词"

- 自动拆成 3 个子任务
- "高级点" → 电影级光影 / HDR / 其他？给选项
- "即梦" → 识别平台黑话，生成对应格式
- "能不能看看" → 先给建议，不直接改

处理省略主语（"这个""那镜"）、程度副词（"稍微""彻底"）、客气表达、行业术语。

## 工作区整洁

成果文件（中文命名）放在任务目录根部，你一眼看到：

```
<任务目录>/
├── 两镜优化建议_v002.txt
├── 镜头2提示词_即梦_v001.txt
└── .工程/（过程文件，隐藏）
```

不被几十个过程文件干扰。自带清理工具，可释放 16% 冗余占用。

## 快速开始

1. **安装**（需要 Codex 或支持 Codex 插件的 AI 代理）：
   ```bash
   codex plugin add skill-orchestrator@skill-orchestrator-private
   ```

2. **第一次使用**：
   ```
   用 $skill-orchestrator 帮我把这个剧本拆成分镜
   ```
   它会问你几个必要的问题（集数、主要角色、时长要求），然后开始工作。

3. **日常使用**（不用每次都说 $skill-orchestrator）：
   ```
   把镜2的光影调电影感一点
   检查镜2到镜3的衔接
   给镜5生成可灵提示词
   ```

## 真实案例

某年会 VCR 项目，开场两个镜头：

- **需求**："九州号主舰从深空驶入星系，16 秒内建立巨物感，屏幕显现航路，切到舰尾露出远处星球"
- **输入**：分镜文字 + 3 张机位参考图
- **过程**：
  - 总导演对齐需求（3 轮追问，明确竖屏区域、尾后角度、屏幕出现时机）
  - 摄影、连续性两岗并行会诊
  - 主控汇总建议
- **产出**：`两镜优化建议_v002.txt`（3 页，含具体机位、时长、切点），`对齐记录_v003.json`（可复用）
- **时长**：约 8 分钟（标准档会诊）

后续逐镜小修（光影、屏幕细节）走轻量档，1-2 分钟搞定。

## 适合谁用

- **短剧制作团队**：导演、编剧、分镜师、剪辑
- **独立创作者**：一人身兼多职，需要 AI 当助手
- **AI 视频创作者**：用即梦、可灵等平台，需要高质量提示词
- **影视专业学生**：学习分镜、导演、剪辑流程

## 技术特性（给开发者）

- **三层能力登记表**：其他插件的技能也能被调度，按领域（剧本/资产/导演/提示词/交付）分包
- **模块化架构**：40 个技能模块，各有独立版本，单独升级不影响其他
- **事件溯源**：正式运行全程留审计，可重放、可导出
- **标准库实现**：索引、桥接、工具都是纯 Python 标准库，不依赖重型框架
- **108 条单元测试**：索引、登记表、桥接、发版工具、可移植性检查、工作区清理
